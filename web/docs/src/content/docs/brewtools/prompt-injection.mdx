# Codewords

<Badge variant="primary" text="brewmod-placeholders" />

The codewords `++m`, `++a`, `++r`, `++rr` and `+++` come from the
[brewmod-placeholders](/mods/placeholders/) mod. Type one in any prompt and the mod adds its instruction block; your prompt still reaches the model as typed.

<Callout type="warning" title="Update brewtools with the mod">
  brewtools 6.7.x also injects these blocks, so each one would appear twice. Use brewtools 6.8.0+ with the mod.
</Callout>

<Callout type="tip" title="Install the mod">
  Run the command below once, then `/reload-plugins`. It needs Claude Code 2.1.301+: run `claude update` first.
</Callout>

```bash
claude plugin install brewmod-placeholders@claude-brewcode
```

## Quick reference

| Item | Value |
|------|-------|
| Provided by | `brewmod-placeholders` mod, [Prompt placeholders](/mods/placeholders/) |
| Related in brewtools | Optional hard wall: [Manager Setup](/brewtools/skills/manager-setup/) |

## Override files

The mod reads codeword override files from these brewtools folders:

| Scope | File location |
|-------|---------------|
| Project | `.claude/brewtools/manager/prompts/<mode>.md` |
| Global | `<config dir>/manager/prompts/<mode>.md` |

Each codeword reads one file name in those folders:

| Override file | Codeword |
|---------------|----------|
| `full.md` | `++m` |
| `planmode.md` | `++m` plan-mode addition |
| `architect.md` | `++a` |
| `review-double.md` | `++r` |
| `review-regression.md` | `++rr` |
| `cron-plan.md` | `+++` plan-mode addition |

To change codeword text, describe the change, for example `/placeholders make ++r shorter`. Claude shows one confirm dialog and saves your own file; it does not edit the override files above. Without a scope word the dialog asks where to save (Global recommended: `~/.claude/placeholders/<name>.md`, all projects; Project: `.claude/placeholders/<name>.md`); start with `global` or `project` to skip the question. A project save outranks both brewtools override folders, a global save only the global one. Full rules: [Prompt placeholders](/mods/placeholders/). `/brewtools:manager-setup status` lists the override files.

## Older Claude Code and Codex

The mod needs Claude Code 2.1.301+ (`claude update`). On an older build, keep brewtools 6.7.x, which still ships the codeword hook. Codex keeps its own codeword hook in the Codex mirror of brewtools; the mod does not apply to it.
