# Codewords (moved to mod)

<Badge variant="accent" text="moved" /> <Badge variant="secondary" text="brewtools v6.8.0" /> <Badge variant="primary" text="brewmod-placeholders" />

The codewords `++m`, `++a`, `++r`, `++rr` and `+++` now come only from the
[brewmod-placeholders](/mods/placeholders/) mod. Brewtools v6.8.0 deleted its own
`UserPromptSubmit` codeword hook. The injected text is unchanged, and your prompt still reaches the model as typed.

<Callout type="warning" title="Update brewtools with the mod">
  Update brewtools to 6.8.0+ together with installing the mod. An older brewtools still ships its own hook, so each block is injected twice.
</Callout>

<Callout type="tip" title="Get the codewords back">
  Requires Claude Code 2.1.292+. Install the mod, then run `/reload-plugins`:

  ```bash
  claude plugin install brewmod-placeholders@claude-brewcode
  ```
</Callout>

## Quick reference

| Item | Value |
|------|-------|
| New home | `brewmod-placeholders` mod, [Prompt placeholders](/mods/placeholders/) |
| Still in brewtools | Optional hard wall: [Manager Setup](/brewtools/skills/manager-setup/) |

## Existing overrides keep working

Your brewtools override files need no migration; the mod reads them through its legacy layer:

| Scope | File location |
|-------|---------------|
| Project | `.claude/brewtools/manager/prompts/<mode>.md` |
| Global | `<config dir>/manager/prompts/<mode>.md` |

Each codeword reads one file name in those folders:

| Override file | Codeword |
|---------------|----------|
| `full.md` | `++m` |
| `planmode.md` | `++m` in Plan mode |
| `architect.md` | `++a` |
| `review-double.md` | `++r` |
| `review-regression.md` | `++rr` |
| `cron-plan.md` | `+++` (Plan mode only) |

Edit codeword text with the mod's `/placeholders edit <name>`; `/brewtools:manager-setup status` lists legacy override files.

## Older Claude Code and Codex

The mod needs Claude Code 2.1.292+. On an older build, keep brewtools 6.7.x, which still ships the codeword hook. Codex keeps its own codeword hook in the Codex mirror of brewtools; the mod does not apply to it.
