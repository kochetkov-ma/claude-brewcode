# Codewords

<Badge variant="primary" text="brewmod-placeholders" />

The codewords `++m`, `++a`, `++r`, `++rr` and `+++` come from the
[brewmod-placeholders](/mods/placeholders/) mod. Type one in any prompt and the mod adds its instruction block; your prompt still reaches the model as typed.

<Callout type="warning" title="Update brewtools with the mod">
  brewtools 6.7.x also injects these blocks, so each one would appear twice. Use brewtools 6.8.0+ with the mod.
</Callout>

<Callout type="tip" title="Install the mod">
  Requires Claude Code 2.1.292+. Install the mod, then run `/reload-plugins`:

  ```bash
  claude plugin install brewmod-placeholders@claude-brewcode
  ```
</Callout>

## Quick reference

| Item | Value |
|------|-------|
| Provided by | `brewmod-placeholders` mod, [Prompt placeholders](/mods/placeholders/) |
| Related in brewtools | Optional hard wall: [Manager Setup](/brewtools/skills/manager-setup/) |

## Override files

The mod reads codeword override files from these brewtools folders:

| Scope | File location |
|-------|---------------|
| Project | `.claude/brewtools/manager/prompts/<mode>.md` |
| Global | `<config dir>/manager/prompts/<mode>.md` |

Each codeword reads one file name in those folders:

| Override file | Codeword |
|---------------|----------|
| `full.md` | `++m` |
| `planmode.md` | `++m` in Plan mode |
| `architect.md` | `++a` |
| `review-double.md` | `++r` |
| `review-regression.md` | `++rr` |
| `cron-plan.md` | `+++` (Plan mode only) |

To change codeword text, describe the change, for example `/placeholders make ++r shorter` (Claude Code 2.1.300+; older builds show the status view and the line `needs Claude Code 2.1.300+ for the dialog`). Claude shows one confirm dialog and saves to your own layer, `.claude/placeholders/<name>.md`, which outranks the override files above; it does not edit them. `/brewtools:manager-setup status` lists the override files.

## Older Claude Code and Codex

The mod needs Claude Code 2.1.292+. On an older build, keep brewtools 6.7.x, which still ships the codeword hook. Codex keeps its own codeword hook in the Codex mirror of brewtools; the mod does not apply to it.
