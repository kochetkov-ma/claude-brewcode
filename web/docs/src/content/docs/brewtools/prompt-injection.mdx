# Codewords (moved to mod)

<Badge variant="accent" text="moved" /> <Badge variant="secondary" text="brewtools v6.8.0" /> <Badge variant="primary" text="brewmod-placeholders" />

The codewords `++m`, `++a`, `++r`, `++rr` and `+++` now come only from the
[brewmod-placeholders](/mods/placeholders/) mod. Brewtools v6.8.0 deleted its own
`UserPromptSubmit` codeword hook, so one provider injects each block. The injected text is
unchanged, and your prompt, including the codeword, still reaches the model as typed.

<Callout type="tip" title="Get the codewords back">
  Requires Claude Code 2.1.292+. Install the mod, then run `/reload-plugins`:

  ```bash
  claude plugin install brewmod-placeholders@claude-brewcode
  ```
</Callout>

## Quick reference

| Item | Value |
|------|-------|
| Moved in | brewtools v6.8.0 |
| New home | `brewmod-placeholders` mod, [Prompt placeholders](/mods/placeholders/) |
| Codewords | `++m`, `++a`, `++r`, `++rr`, `+++` (Plan mode only) |
| Needs | Claude Code 2.1.292+ |
| Still in brewtools | The optional manager hard wall, via [Manager Setup](/brewtools/skills/manager-setup/) |

## Existing overrides keep working

Override files you wrote for brewtools need no migration. The mod reads them through its
legacy layer:

| Scope | File location |
|-------|---------------|
| Project | `.claude/brewtools/manager/prompts/<mode>.md` |
| Global | `<config dir>/manager/prompts/<mode>.md` |

Each codeword reads one override file name in those folders (the `legacy` key of the mod's default):

| Override file | Codeword |
|---------------|----------|
| `full.md` | `++m` |
| `planmode.md` | `++m` in Plan mode |
| `architect.md` | `++a` |
| `review-double.md` | `++r` |
| `review-regression.md` | `++rr` |
| `cron-plan.md` | `+++` (Plan mode only) |

To change codeword text from now on, use the mod's `/placeholders edit <name>`.
`/brewtools:manager-setup status` lists any legacy override files it finds.

## Staying on an older Claude Code

The mod needs Claude Code 2.1.292+. On an older build, keep brewtools 6.7.x, which still
ships the codeword hook.

## Codex

Codex keeps its own codeword hook in the Codex mirror of brewtools. The mod is a Claude Code
feature and does not apply to Codex.
