# text-human -- universal AI artifact humanizer

<Badge text="sonnet" /> <Badge text="model-invocable" />

Give it a commit hash, a file, a folder or pasted text. The skill picks the matching flow, strips validated AI tells, then applies a gated human style that fits the domain.

<Callout type="caution">
The skill cleans surface artifacts such as self-attribution comments and repetitive prose. Ticket IDs, Unicode and comments can carry real meaning, so appearance alone never justifies a behavior change. It does not detect authorship.
</Callout>

## Quick reference

| Field | Value |
|-------|-------|
| Command | `/brewtools:text-human` |
| Arguments | `[prompt] [path\|commit\|folder\|text] [custom instructions]` |
| Model | sonnet (haiku for simple blocks in mixed flow) |
| Invocation | Model-invocable (`disable-model-invocation: false`): type the command or ask Claude ("humanize this README", "strip AI artifacts from this commit message") |
| Output | In-place edits plus a Humanization Report |

## When to use

| Situation | Command |
|-----------|---------|
| After an AI-assisted commit: clean all touched files (current worktree content, not the historical blob) | `/brewtools:text-human 3be67487` |
| Before review: strip AI markers from a folder | `/brewtools:text-human src/main/java/services/` |
| JavaDoc / API docs: remove param restates, keep contracts | `/brewtools:text-human clean the javadoc in PaymentApi.java` |
| README or guide: fix metronomic prose | `/brewtools:text-human docs/getting-started.md` |
| Reddit or Slack reply: casual register | `/brewtools:text-human review this reddit reply: <text>` |
| Blog post or essay: burstiness and stance | `/brewtools:text-human humanize this blog post: <text>` |
| Strip only, no inject | `/brewtools:text-human src/ only strip AI artifacts, no inject` |
| Custom rule on top of defaults | `/brewtools:text-human 3be67487 also drop all @author tags` |

## Example

```text
/brewtools:text-human 3be67487
```

Mixed flow routes each changed file to its domain, then prints a Humanization Report: flow, scope, files, strip/inject counts and items surfaced for review. No arguments in an interactive session asks once; a headless run, or no answer, stops with "nothing to humanize" and edits nothing.

## How it works

<Steps>
  <li><div><strong>Detect the flow</strong><p>Intent keywords (RU+EN), then path/extension, then content sniff. The skill announces `Flow: <name> -- <why>` and loads only that flow.</p></div></li>
  <li><div><strong>Parse the scope</strong><p>The first token is scope if it is an existing path or a 7+ hex hash; the rest is a custom prompt with top priority.</p></div></li>
  <li><div><strong>Check the tree</strong><p>No backup exists, so `git status --porcelain` runs over the targets. Dirty paths trigger one question: proceed, clean only, or abort. Inline text skips this.</p></div></li>
  <li><div><strong>Strip</strong><p>Chat scaffolding, self-attribution, prompt residue and unicode in prose act on single hits; density signals act on clusters.</p></div></li>
  <li><div><strong>Inject (gated)</strong><p>Domain-tuned human style. Off for code and API docs; never typos, errors or invented references.</p></div></li>
  <li><div><strong>Report</strong><p>Results merge into one report. Files are edited in place; review the diff.</p></div></li>
</Steps>

## Good to know

- Behavior-changing findings (hallucinated refs, fabricated tickets, try/except-everywhere, unicode inside a string literal or regex) are surfaced, never auto-edited.
- Kept as is: WHY comments, public API docs, real tickets of any pattern, conditional `@throws`, structural banners, BDD comments, lint/type/license directives.
- Read-only git calls (`git status`, `git rev-parse`, `git diff --name-only`) run without a prompt; edits follow your permission mode.

<Spoiler id="delegation" title="Delegation (mixed flow)">

A commit or folder splits into blocks of about 5 files; each subagent gets the six-field brief and all blocks start in one message. Haiku takes simple content, sonnet logic, tests and complex SQL. Field table: [Delegation](/brewcode/skills/#delegation).

Functional preservation overrides cosmetic cleanup: GIVEN/WHEN/THEN and Arrange/Act/Assert comments and lint, type, security, build, license and coverage directives stay byte-for-byte, including unexplained `noqa` or ESLint suppressions. Real tickets stay unless proven invented against the tracker; uncertainty is reported, not guessed away.

</Spoiler>

<Spoiler id="internals" title="Flows, strip catalog and injection weights">

| Flow | Domain | Inject stage |
|------|--------|--------------|
| code | source, comments, docstrings, JavaDoc/JSDoc/KDoc | OFF |
| docs | README, guides, PR/commit, changelogs | ON, restrained (terse for PR/commit) |
| social | reddit, forum, slack, discord, chat | ON, casual |
| article | formal essay, published blog, long-form | ON, full |
| mixed | commit / folder dispatcher | per-file routing |

| Strip category | Example | Tier |
|----------------|---------|------|
| Chat scaffolding | "Certainly!", "I hope this helps" | HIGH |
| AI self-attribution | `// AI-generated`, bot/co-author trailers | HIGH |
| Prompt residue | `// Replace with your...` | HIGH |
| Unicode in prose and code comments | em-dash, smart quotes, arrows -> ASCII | HIGH |
| Promotional openers | "In today's fast-paced world" | HIGH/MED |
| Trivial comment/docstring | `// Loop through users` | MED density |
| Excess-vocab cluster | delve, leverage, seamless | MED cluster only |

| Signal | reddit | chat | docs | commit/PR | article | code/API |
|--------|--------|------|------|-----------|---------|----------|
| Burstiness | high | high | med | low | high | OFF |
| Contractions | high | high | OK | low | high | FORBIDDEN |
| Stance | high | med | none | grounded-why | high | FORBIDDEN |
| Emoji | rare | incidental | no | no | no | no |

| Files | Lines | Blocks |
|-------|-------|--------|
| 1-2 | under 200 | 1 (direct) |
| 3-5 | under 500 | 3 |
| 6-10 | 500-1500 | 5 |
| 11-20 | 1500-3000 | 7 |
| 21+ | 3000+ | 10 |

Permissions: when Claude starts the skill, Claude Code asks once for the `Skill` call in default mode; headless and `dontAsk` runs need `Skill(brewtools:text-human *)` in settings. Pre-approved tools: `Read, Grep, Glob, Agent, AskUserQuestion` (no Bash rule).

</Spoiler>
