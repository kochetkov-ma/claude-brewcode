# Provider Switch

Configure DeepSeek, Z.ai/GLM, Qwen/DashScope, MiniMax or OpenRouter for Claude Code. The skill writes a provider alias to `~/.zshrc`, keeps existing choices unless you select a change, and offers status and connectivity checks. Provider billing and rate limits are separate from your Anthropic subscription.

## Quick reference

| Field | Value |
|-------|-------|
| Command | `/brewtools:provider-switch [prompt] [status\|install\|verify\|model-check\|help\|<provider-name>]` |
| Default | Read-only status, never an install |
| Output | Provider alias and selected configuration in `~/.zshrc` |
| Model | opus |
| Credentials | Existing shell environment variable or private local file; never paste keys into chat |

## Modes

| Argument | Mode | What it does |
|----------|------|--------------|
| (none) | status | Provider table, read-only; prints the install command if nothing is configured |
| `install` | install | Interactive selection of one or more providers |
| `deepseek` / `ds` / `dpsk` | provider-deepseek | Configure DeepSeek V4 only (priority default) |
| `glm` / `zai` / `z.ai` | provider-glm | Configure Z.ai/GLM only |
| `qwen` / `dashscope` | provider-qwen | Configure Qwen/DashScope only |
| `minimax` / `mini` | provider-minimax | Configure MiniMax only |
| `openrouter` / `router` | provider-openrouter | Configure OpenRouter and pick a model |
| `help` / `how` | help | How aliases, env vars and dashboards work |
| `verify` / `test` | verify | Minimal API request to each configured endpoint; can consume provider usage |
| `model-check` / `identify` | model-check | 5 diagnostic questions to identify the model; run inside a provider session |

## Setup

<Steps>
  <li><div><strong>Choose the provider</strong><p>Get a key in that provider's console. For Qwen, identify billing product, region and workspace first.</p></div></li>
  <li><div><strong>Run the skill</strong><p>Use <code>/brewtools:provider-switch install</code> or name a provider. Supply the key through a shell variable or a private file, then confirm alias and models.</p></div></li>
  <li><div><strong>Launch a session</strong><p>Load the alias in your shell and run it. To return to Anthropic, launch from a shell without the provider overrides.</p></div></li>
</Steps>

Default aliases: `claudeds`, `claudeglm`, `claudeqwen`, `claudeminimax`, `claudeor`; custom names start with `claude` and use lowercase letters and digits only.

## Providers, models and pricing

One model serves all four roles (opus, sonnet, haiku, fable), so subagents pinned to any of them stay on the provider. USD per 1M tokens, input/output, per the skill's references checked 2026-10-12; confirm on the provider page.

| Provider | Alias | Model | Direct price | Reference |
|----------|-------|-------|--------------|-----------|
| DeepSeek V4 (priority) | `claudeds` | `deepseek-v4-pro`, 1M context | $1.32 / $3.96 peak, $0.66 / $1.98 off-peak (cache miss) | [Pricing](https://api-docs.deepseek.com/quick_start/pricing/) |
| Z.ai / GLM | `claudeglm` | `glm-5.2`, 1M context | $1.40 / $4.40 | [Pricing](https://docs.z.ai/guides/overview/pricing) |
| Qwen / DashScope | `claudeqwen` | `qwen3.7-plus[1m]` | $0.40 / $1.60 up to 256K input, $1.20 / $4.80 above | [Claude Code guide](https://www.alibabacloud.com/help/en/model-studio/claude-code), [pricing](https://www.alibabacloud.com/help/en/model-studio/model-pricing) |
| MiniMax | `claudeminimax` | `MiniMax-M3`, up to 1M context | $0.30 / $1.20 up to 512K, $0.60 / $2.40 above | [Pricing](https://platform.minimax.io/docs/guides/pricing-paygo) |
| OpenRouter | `claudeor` | user-selected, default `qwen/qwen3.7-plus[1m]` | route-dependent | [Live catalog](https://openrouter.ai/api/v1/models) |

DeepSeek is the priority provider by configuration policy, not benchmark. Direct and OpenRouter prices differ; cache support depends on provider and route.

<Spoiler id="qwen-region-workspace-and-plan" title="Qwen: key, region and plan">

A key works only with the endpoint of the region, workspace and billing product it was created in (pay-as-you-go: Beijing, Singapore, Virginia; Coding Plan and Token Plan use others). The default alias uses `dashscope-intl.aliyuncs.com`, so create the key in the matching region. Prefix or length reveals nothing about region. An existing endpoint is kept unless you change it.

</Spoiler>

<Spoiler id="openrouter-selection" title="OpenRouter model selection">

Every selected ID (menu, default or custom) must match the live public catalog exactly. A missing ID gets suggestions and at most two retries; a fetch or parser failure writes nothing. The ID fills all four role slots with no automatic `[1m]` suffix. See the [variant reference](https://openrouter.ai/docs/guides/routing/model-variants/overview).

</Spoiler>

<Spoiler id="credentials-and-compatibility" title="Credentials, environment variables and compatibility flags">

- Keys enter the writer on stdin, never as arguments. A key file readable by group or world is refused until `chmod 600`.
- The shell backup is private and removed after a successful write.

Each alias exports seven variables: `ANTHROPIC_BASE_URL`, `ANTHROPIC_AUTH_TOKEN`, an explicit empty `ANTHROPIC_API_KEY` (avoids OAuth fallback), and `ANTHROPIC_DEFAULT_OPUS_MODEL`, `ANTHROPIC_DEFAULT_SONNET_MODEL`, `ANTHROPIC_DEFAULT_HAIKU_MODEL`, `ANTHROPIC_DEFAULT_FABLE_MODEL`.

| Provider | Compatibility flags |
|----------|---------------------|
| DeepSeek, OpenRouter | None |
| Z.ai / GLM and MiniMax | `CLAUDE_ENABLE_BYTE_WATCHDOG=0`, `CLAUDE_CODE_DISABLE_EXPERIMENTAL_BETAS=1` |
| Qwen / DashScope | `CLAUDE_CODE_DISABLE_EXPERIMENTAL_BETAS=1` |

</Spoiler>

<Spoiler id="reference-refresh" title="Reference refresh">

One research agent per provider ([delegation](/brewcode/skills/#delegation)) returns a Current/Fetched/Source table; verified differences are shown for your choice before any write.

</Spoiler>
