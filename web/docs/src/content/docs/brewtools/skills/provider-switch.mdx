# Provider Switch

Configure DeepSeek, Z.ai/GLM, Qwen/DashScope, MiniMax or OpenRouter for Claude Code.
The skill writes a provider alias to `~/.zshrc`, keeps existing choices unless you select a change,
and provides status and connectivity checks. Provider billing, model support and rate limits
remain separate from your Anthropic subscription.

## Quick reference

| Field | Value |
|-------|-------|
| Command | `/brewtools:provider-switch [prompt] [status\|install\|verify\|model-check\|help\|<provider-name>]` |
| Default | Read-only status |
| Output | Provider alias and selected configuration in `~/.zshrc` |
| Model | opus |
| Credentials | Existing shell environment variable or private local file; never paste keys into chat |

## When to use

- Configure an alternative provider for a new Claude Code session.
- Inspect existing aliases and model selections without changing them.
- Check connectivity or refresh provider reference information before a requested change.

## Setup

<Steps>
  <li><div><strong>Choose the provider</strong><p>Get a key through that provider's console. For Qwen, identify the billing product, region and workspace before choosing an endpoint.</p></div></li>
  <li><div><strong>Run the skill</strong><p>Use <code>/brewtools:provider-switch install</code> or name one provider. Supply the key through an existing shell variable or a private file. Confirm the alias and model choices.</p></div></li>
  <li><div><strong>Launch a session</strong><p>Load the new alias in your shell, then run it to start Claude Code. The alias sets provider variables before launch. To return to Anthropic, launch from a shell without those provider overrides.</p></div></li>
</Steps>

```text
/brewtools:provider-switch status
/brewtools:provider-switch install
/brewtools:provider-switch openrouter
```

```bash
claudeds       # DeepSeek
claudeglm      # Z.ai / GLM
claudeqwen     # Qwen / DashScope
claudeminimax  # MiniMax
claudeor       # OpenRouter, user-selected catalog model
```

These are default alias names; custom names begin with `claude` and contain lowercase
letters and digits only. Existing model and endpoint choices survive a reference refresh.

## Providers, models and pricing

Model catalogs and prices change. Check the direct provider's current terms for region,
context tier, input/output, cache hits and your billing product before choosing a model.
Provider references were refreshed on 2026-09-30. Use these primary catalogs and pricing pages
before setup, rather than assuming a fixed monthly cost or comparative quality ranking.

| Provider | Alias | Primary reference |
|----------|-------|-------------------|
| DeepSeek | `claudeds` | [Models and pricing](https://api-docs.deepseek.com/quick_start/pricing/) |
| Z.ai / GLM | `claudeglm` | [Pricing](https://docs.z.ai/guides/overview/pricing) |
| Qwen / DashScope | `claudeqwen` | [Claude Code integration](https://www.alibabacloud.com/help/en/model-studio/claude-code) and [model pricing](https://www.alibabacloud.com/help/en/model-studio/model-pricing) |
| MiniMax | `claudeminimax` | [Pay-as-you-go pricing](https://platform.minimax.io/docs/guides/pricing-paygo) |
| OpenRouter | `claudeor` | [Live catalog](https://openrouter.ai/api/v1/models) and [model variants](https://openrouter.ai/docs/guides/routing/model-variants/overview) |

DeepSeek remains the repository's priority provider; that is a configuration policy, not a
benchmark claim. Direct-provider pricing and OpenRouter routing prices can differ. Prompt
cache support, thresholds and TTL depend on the provider and route; check the current reference
and response/billing evidence instead of assuming a universal discount.

### Qwen region, workspace and plan

Match the key to the endpoint's region, workspace and billing product. The official integration
lists pay-as-you-go endpoints for Beijing, Singapore and Virginia, and different endpoints for
Coding Plan and Token Plan. Region or key validity cannot be inferred from its prefix or length.
The skill preserves an existing endpoint unless you select a change. See the
[Alibaba Cloud integration guide](https://www.alibabacloud.com/help/en/model-studio/claude-code).

### OpenRouter selection

Before presenting model choices, the skill refreshes the public catalog and verifies every
selected ID, including menu, default and custom selections. A successful fetch, valid JSON and
an exact catalog match are required. Missing IDs prompt suggestions and at most two retries;
request/parser failures are reported as verification failures. No model is written on failure,
and there is no automatic replacement of the user's configured model.

The selected ID maps to Opus, Sonnet and Haiku slots together. OpenRouter IDs are not given an
automatic `[1m]` suffix. Context length and capabilities come from the selected catalog entry;
provider routing suffixes have their own rules in the
[OpenRouter variant reference](https://openrouter.ai/docs/guides/routing/model-variants/overview).

## Verification

| Command | Result and limit |
|---------|------------------|
| `status` | Read-only configured-provider table |
| `verify` | Minimal API requests to configured providers; can consume provider usage and reports actual responses |
| `model-check` | In-session model diagnostics after launching an alias; model self-identification alone is not authoritative identity proof |
| `help` | Switching reference |

A catalog lookup is public and unauthenticated. It proves an ID is listed, not that your account
can use it or that a paid inference request succeeded.

## Credentials and compatibility

Keys enter the writer on stdin rather than command arguments. Connectivity checks pass secrets
through curl configuration input; the model-list lookup needs no auth header. The shell backup
is private and cleaned after a successful write. Do not paste a runtime secret into an
`AskUserQuestion` answer or a report.

| Provider | Compatibility flags installed from its reference |
|----------|--------------------------------------------------|
| DeepSeek | None |
| Z.ai / GLM and MiniMax | `CLAUDE_ENABLE_BYTE_WATCHDOG=0`, `CLAUDE_CODE_DISABLE_EXPERIMENTAL_BETAS=1` |
| Qwen / DashScope | `CLAUDE_CODE_DISABLE_EXPERIMENTAL_BETAS=1` |
| OpenRouter | None |

Aliases set `ANTHROPIC_AUTH_TOKEN` and an explicit empty `ANTHROPIC_API_KEY` along with the
base URL and model mapping. This avoids unintended OAuth fallback. Supported context settings
are provider-specific; a model-name hint cannot create context capacity a provider does not offer.

## Reference refresh

The main coordinator dispatches one bounded research agent per provider using `Agent`, with
GOAL, ROLE, SCOPE, CONTEXT, CONSUMER and DONE. Each returns a Current/Fetched/Source URL table
for model IDs, pricing and endpoints; it does not edit shell configuration. The skill presents
verified differences for user selection before writes, preserving choices that were not changed.
