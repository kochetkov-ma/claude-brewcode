# Skills

Skills are slash commands that define what to do. Brewtools has 13: text processing, secrets scanning, SSH, deployment, plugin management, subagent budgeting and session orchestration. Each works on its own; the `-setup` skills first install a mechanism into a project or profile.

## Summary table

| # | Skill | Model | Purpose |
|---|-------|-------|---------|
| 1 | [agent-deadline-setup](/brewtools/skills/agent-deadline-setup/) | sonnet | Soft wall-clock budget for subagents: warns at 80%, blocks non-finalizing tools past 100% |
| 2 | [agent-return-setup](/brewtools/skills/agent-return-setup/) | sonnet | Size budget on every subagent's final return: blocks once, orders compress or write-to-report |
| 3 | [agent-router-setup](/brewtools/skills/agent-router-setup/) | sonnet | EXPERIMENTAL. Denies a generic subagent spawn when a real project/plugin expert owns the task |
| 4 | [context-slim](/brewtools/skills/context-slim/) | opus | Compresses what permanently enters the LLM context: CLAUDE.md, rules, agent descriptions, hooks, memory |
| 5 | [deploy](/brewtools/skills/deploy/) | opus | GitHub Actions deployment: workflows, releases, GHCR, CI/CD with safety gates |
| 6 | [manager-setup](/brewtools/skills/manager-setup/) | sonnet | Opt-in project delegation wall and task-tools env merge |
| 7 | [plugin-update](/brewtools/skills/plugin-update/) | sonnet | Updates every outdated plugin and mod in one run, offers the missing ones once, reports versions before and after |
| 8 | [provider-switch](/brewtools/skills/provider-switch/) | opus | Alternative API providers: DeepSeek, Z.ai/GLM, Qwen, MiniMax, OpenRouter |

<ModPromo variant="strip" />

Setup skills share `status | install | upgrade | enable | disable | uninstall | purge`; `manager-setup` defaults to read-only `status`. `text-optimize` and `text-human` are model-invocable; the rest run only when you type them (see the [FAQ](/faq/#auto-invoke)). The codewords `++m ++a ++rr ++r +++` come from the [placeholders mod](/mods/placeholders/).

## How these skills delegate

One subagent = one bounded unit; the spawn rules live in [Brewcode: Delegation](/brewcode/skills/#delegation).

<Spoiler id="bounded-units" title="One bounded unit per skill">

| Skill | One bounded unit is... |
|-------|------------------------|
| [agent-deadline-setup](/brewtools/skills/agent-deadline-setup/), [agent-return-setup](/brewtools/skills/agent-return-setup/) | one mode-and-scope combination: a single `brewcode:hook-creator` spawn |
| [agent-router-setup](/brewtools/skills/agent-router-setup/) | one mode: a single `brewcode:hook-creator` spawn |
| [context-slim](/brewtools/skills/context-slim/) | one file: a `text-optimizer` spawn per file, all in one message |
| [deploy](/brewtools/skills/deploy/) | one deliverable, one repo, one environment; confirmation gates stay in the main conversation |
| [provider-switch](/brewtools/skills/provider-switch/) | one provider: five research agents, one message |
| [secrets-scan](/brewtools/skills/secrets-scan/) | one chunk of the file list; a bigger repo gets more chunks |
| [ssh](/brewtools/skills/ssh/) | one deliverable on one host; DELETE/PRIVILEGE approval happens before any spawn |
| [task-board-setup](/brewtools/skills/task-board-setup/) | one doc group |
| [text-human](/brewtools/skills/text-human/) | one block of files from the commit or folder |
| [text-optimize](/brewtools/skills/text-optimize/) | one file: a folder run is split one file per agent |

[plugin-update](/brewtools/skills/plugin-update/) runs its commands in the main conversation. `manager-setup` can delegate a task while keeping wall configuration in the main session. `task-board-setup` runs one timer per active top-level task, hourly unless overridden; child units share the parent timer.

</Spoiler>
