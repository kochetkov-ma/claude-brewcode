# Brewui Overview

Brewui is a placeholder plugin for future UI/visual/creative tools. It ships no [skills](/brewui/skills/), [agents](/brewui/agents/), or hooks yet, but installs cleanly, so it can be wired into your suite ahead of time.

## Installation

<InstallPrompt plugin="brewui" mode="install" />

Whole suite (plugins and mods): the mods need Claude Code 2.1.301 or newer, so run `claude update`, then restart Claude Code (type `exit`, then run `claude`).

<InstallPrompt plugin="all" mode="install" />

<Callout type="note" title="Brewui vs Brewcode">
  Brewui is reserved for standalone visual/creative tools and is currently empty. Brewcode is the authoring toolkit: skills, agents, rules, semantic search, conventions, E2E tests. Both install from the `claude-brewcode` marketplace and run independently.
</Callout>

## Architecture

```
brewui/
├── .claude-plugin/plugin.json   # Plugin manifest
└── skills/                      # Empty, reserved for future tools
```
