# Installation

These four products run in Claude Code: 27 skills, 9 agents, and 3 registered plugin hooks.

<InstallPrompt plugin="all" mode="install" />

<Callout type="note" title="Claude Code only">
  The repository's native Codex instructions are separate; this installation does not enable Codex plugins or configure Codex authentication or runtime state.
</Callout>

## Requirements

| Component | Version | Purpose |
|-----------|---------|---------|
| Claude Code CLI | 2.1.296 authoring reference | Runtime contracts checked for this release; not a declared minimum version |
| Node.js | 20+ | Hook runtime |
| macOS | 13+ | Supported OS |

<Callout type="warning" title="macOS">
  Brewcode supports macOS only. Linux and Windows support is planned for future releases.
</Callout>

## Installation methods

<Tabs>
  <TabItem label="Marketplace (recommended)">
    Permanent installation through the Claude Code plugin system. Plugins load automatically with every session.

    **1. Add the marketplace** -- registers the plugin source:

    ```bash
    claude plugin marketplace add https://github.com/kochetkov-ma/claude-brewcode
    ```

    **2. Install the plugins** -- installs all four products:

    ```bash
    claude plugin install brewcode@claude-brewcode
    claude plugin install brewdoc@claude-brewcode
    claude plugin install brewtools@claude-brewcode
    claude plugin install brewui@claude-brewcode
    ```

    **3. Reload the plugins** -- run `/reload-plugins` inside a session. If the command is unavailable, type `exit` and run `claude` again.
  </TabItem>
  <TabItem label="Local directory (developers only)">
    Run from a cloned repository. Suitable for plugin development or one-off use.

    **1. Clone the repository:**

    ```bash
    git clone https://github.com/kochetkov-ma/claude-brewcode.git
    cd claude-brewcode
    ```

    **2. Launch with the `--plugin-dir` flag** (developers only):

    ```bash
    claude --plugin-dir ./brewcode --plugin-dir ./brewdoc --plugin-dir ./brewtools --plugin-dir ./brewui
    ```

    For a single plugin (developers only):

    ```bash
    claude --plugin-dir ./brewcode
    claude --plugin-dir ./brewtools
    claude --plugin-dir ./brewui
    ```
  </TabItem>
</Tabs>

## Mods (optional)

[Brewcode mods](/mods/overview/) are separate plugins that extend Claude Code itself through the hooks module API. They are not part of the four-plugin suite and are never installed with it. After adding the marketplace, install the ones you want: [`brewmod-plan-effort`](/mods/plan-effort/) and [`brewmod-placeholders`](/mods/placeholders/).

```bash
claude plugin install brewmod-plan-effort@claude-brewcode    # Claude Code 2.1.287+
claude plugin install brewmod-placeholders@claude-brewcode   # Claude Code 2.1.292+
```

Then run `/reload-plugins`. [`/brewtools:plugin-update`](/brewtools/skills/plugin-update/) keeps installed mods current.

<Spoiler id="updating" title="Updating">
  <Callout type="tip" title="Easy path: plugin-update skill">
    Run <a href="/brewtools/skills/plugin-update/"><code>/brewtools:plugin-update</code></a> inside a Claude Code session. It checks versions, runs the full update chain, and prompts you to reload.
  </Callout>

  Or run the update commands manually:

  ```bash
  claude plugin marketplace update claude-brewcode
  claude plugin update brewcode@claude-brewcode
  claude plugin update brewdoc@claude-brewcode
  claude plugin update brewtools@claude-brewcode
  claude plugin update brewui@claude-brewcode
  ```

  Run `/reload-plugins` inside your session (preferred), or type `exit` and run `claude` again. Updates are not active until a reload. Then rerun setup-status: plugin updates do not replace artifacts that a setup copied into your project, so follow its scope-specific upgrade commands.

  <InstallPrompt plugin="all" mode="update" />
</Spoiler>

<Spoiler id="troubleshooting" title="Troubleshooting">
  **Plugins don't appear in `claude plugin list`**: add the marketplace with `claude plugin marketplace add https://github.com/kochetkov-ma/claude-brewcode`, reinstall and restart Claude Code.

  **`/brewcode:*` commands are not recognized**: restart Claude Code. Plugins only load at session start.

  **`timeout` command missing on macOS**: the semble-setup scripts use `timeout`/`gtimeout` when present and fall back to a pure-bash timer. `brew install coreutils` gives the native one.

  **`CLAUDECODE` environment variable interferes with launch**: run `unset CLAUDECODE` before `claude` in scripts (v0.2.47+).
</Spoiler>
