# Installation

These four products run in Claude Code: 27 skills, 10 agents, and 3 registered plugin hooks. The prompt below also installs the two [brewcode mods](#mods), placeholders first, after it checks that Claude Code is 2.1.301 or newer.

<InstallPrompt plugin="all" mode="install" />

<Callout type="note" title="Claude Code only">
  The repository keeps separate native instructions for Codex. This installation does not enable Codex plugins or change Codex authentication or runtime state.
</Callout>

## Requirements

| Component | Version | Purpose |
|-----------|---------|---------|
| Claude Code CLI | 2.1.296 authoring reference | Runtime contracts checked for this release; not a declared minimum for the four plugins. The [mods](#mods) need 2.1.301 or newer |
| Node.js | 20+ | Hook runtime |
| macOS | 13+ | Supported OS |

<Callout type="warning" title="macOS">
  Brewcode supports macOS only. Linux and Windows support is planned for future releases.
</Callout>

## Installation methods

<Tabs>
  <TabItem label="Marketplace (recommended)">
    Permanent installation through the Claude Code plugin system. Plugins load automatically with every session.

    **1. Update Claude Code** -- the mods need 2.1.301 or newer. Check `claude --version`; if it is lower, run `claude update`, then restart Claude Code (`exit`, then `claude`).

    **2. Add the marketplace** -- registers the plugin source:

    ```bash
    claude plugin marketplace add https://github.com/kochetkov-ma/claude-brewcode
    ```

    **3. Install the mods and the plugins** -- both mods, then all four products, one name per command:

    ```bash
    claude plugin install brewmod-placeholders@claude-brewcode
    claude plugin install brewmod-plan-effort@claude-brewcode
    claude plugin install brewcode@claude-brewcode
    claude plugin install brewdoc@claude-brewcode
    claude plugin install brewtools@claude-brewcode
    claude plugin install brewui@claude-brewcode
    ```

    **4. Reload the plugins** -- run `/reload-plugins` inside a session. If the command is unavailable, or you just ran `claude update`, type `exit` and run `claude` again.
  </TabItem>
  <TabItem label="Local directory (developers only)">
    Run from a cloned repository. Suitable for plugin development or one-off use.

    **1. Clone the repository:**

    ```bash
    git clone https://github.com/kochetkov-ma/claude-brewcode.git
    cd claude-brewcode
    ```

    **2. Launch with the `--plugin-dir` flag:**

    ```bash
    claude --plugin-dir ./brewcode --plugin-dir ./brewdoc --plugin-dir ./brewtools --plugin-dir ./brewui
    ```

    For a single plugin:

    ```bash
    claude --plugin-dir ./brewcode
    claude --plugin-dir ./brewtools
    claude --plugin-dir ./brewui
    ```
  </TabItem>
</Tabs>

## Mods

[Brewcode mods](/mods/overview/) are separate plugins that extend Claude Code itself through the hooks module API. They are counted apart from the four plugins, and the install above covers both: [`brewmod-placeholders`](/mods/placeholders/) first, then [`brewmod-plan-effort`](/mods/plan-effort/).

<Callout type="warning" title="Update Claude Code first">
  The mods need Claude Code 2.1.301 or newer. Check with `claude --version`; if it is lower, run `claude update` and restart Claude Code (`exit`, then `claude`).
</Callout>

To add the mods to a machine that already has the plugins, run:

```bash
claude update
claude plugin install brewmod-placeholders@claude-brewcode
claude plugin install brewmod-plan-effort@claude-brewcode
```

Restart Claude Code after `claude update`. When Claude Code was already 2.1.301 or newer, `/reload-plugins` is enough.

<Spoiler id="updating" title="Updating">
  Run [`/brewtools:plugin-update`](/brewtools/skills/plugin-update/) in a session to update every installed plugin and mod and offer the missing ones in one question, then `/reload-plugins`, then `/brewcode:setup-status upgrade` in each project.

  Or run the update commands manually, then reload and upgrade as above. The mods need Claude Code 2.1.301 or newer: if `claude --version` is lower, run `claude update` and restart Claude Code first. Run one `claude plugin update` per installed plugin; a second name in one call is silently ignored:

  ```bash
  claude plugin marketplace update claude-brewcode
  claude plugin update brewmod-placeholders@claude-brewcode
  claude plugin update brewmod-plan-effort@claude-brewcode
  claude plugin update brewcode@claude-brewcode
  claude plugin update brewdoc@claude-brewcode
  claude plugin update brewtools@claude-brewcode
  claude plugin update brewui@claude-brewcode
  ```

  Skip the lines of plugins you did not install.

  <InstallPrompt plugin="all" mode="update" />
</Spoiler>

<Spoiler id="troubleshooting" title="Troubleshooting">
  **Plugins don't appear in `claude plugin list`**: add the marketplace with `claude plugin marketplace add https://github.com/kochetkov-ma/claude-brewcode`, reinstall and restart Claude Code.

  **`/brewcode:*` commands are not recognized**: restart Claude Code. Plugins only load at session start.

  **`timeout` command missing on macOS**: the semble-setup scripts use `timeout`/`gtimeout` when present and fall back to a pure-bash timer. `brew install coreutils` gives the native one.

  **`CLAUDECODE` environment variable interferes with launch**: run `unset CLAUDECODE` before `claude` in scripts (v0.2.47+).
</Spoiler>
