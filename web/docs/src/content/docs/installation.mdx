# Installation

<InstallPrompt plugin="all" mode="install" />

## Requirements

| Component | Version | Purpose |
|-----------|---------|---------|
| Claude Code CLI | latest | Plugin runtime |
| Node.js | 20+ | Hook runtime |
| macOS | 13+ | Supported OS |

<Callout type="warning" title="macOS">
  Brewcode supports macOS only. Linux and Windows support is planned for future releases.
</Callout>

## Installation methods

<Tabs>
  <TabItem label="Marketplace (recommended)">
    Permanent installation through the Claude Code plugin system. Plugins load automatically with every session.

    **1. Add the marketplace** -- registers the plugin source:

    ```bash
    claude plugin marketplace add https://github.com/kochetkov-ma/claude-brewcode
    ```

    **2. Install the plugins** -- copies both plugins to the local cache:

    ```bash
    claude plugin install brewcode@claude-brewcode
    claude plugin install brewdoc@claude-brewcode
    claude plugin install brewtools@claude-brewcode
    claude plugin install brewui@claude-brewcode
    ```

    **3. Restart Claude Code** -- the plugins will load automatically.
  </TabItem>
  <TabItem label="Local directory (developers only)">
    Run from a cloned repository. Suitable for plugin development or one-off use.

    **1. Clone the repository:**

    ```bash
    git clone https://github.com/kochetkov-ma/claude-brewcode.git
    cd claude-brewcode
    ```

    **2. Launch with the `--plugin-dir` flag** (developers only):

    ```bash
    claude --plugin-dir ./brewcode --plugin-dir ./brewdoc --plugin-dir ./brewtools --plugin-dir ./brewui
    ```

    For a single plugin (developers only):

    ```bash
    claude --plugin-dir ./brewcode
    claude --plugin-dir ./brewtools
    claude --plugin-dir ./brewui
    ```
  </TabItem>
</Tabs>

## Verifying the installation

<Steps>
  <li class="step step-primary">
    <div>
      <strong>Install the plugins</strong>
      <p>Run the commands from the section above. Restart Claude Code after installation.</p>
    </div>
  </li>
  <li class="step step-primary">
    <div>
      <strong>Check the plugin list</strong>
      <p>In your terminal, run:</p>
      <pre><code>claude plugin list</code></pre>
      <p>You should see <code>brewcode</code>, <code>brewdoc</code>, <code>brewtools</code>, and <code>brewui</code> in the list.</p>
    </div>
  </li>
  <li class="step step-primary">
    <div>
      <strong>Set up the task board</strong>
      <p>Inside a Claude Code session, run:</p>
      <pre><code>/brewtools:task-board-setup install . "one lane per service"</code></pre>
      <p>It analyzes the repo and deploys a file-based Kanban plus a generated <code>/task-spec</code> skill for per-task specs. In a <em>separate</em> session, follow it with <a href="/brewcode/skills/superreview-setup/"><code>/brewcode:superreview-setup</code></a> to generate a project-tailored deep-review skill. See <a href="/brewtools/skills/task-board-setup/">the skill page</a> for the full argument list.</p>
    </div>
  </li>
  <li class="step step-primary">
    <div>
      <strong>See what else this project needs</strong>
      <p>Run the read-only dashboard, then work through the list it gives you, one setup per session:</p>
      <pre><code>/brewcode:setup-status</code></pre>
      <p>It writes nothing and runs nothing — it reports every setup as installed, stale, disabled,
      partial or missing, and prints the exact command for each row. The full ordered run list is on
      the <a href="/full-setup/">Full Setup</a> page.</p>
    </div>
  </li>
</Steps>

## Updating

Already have Brewcode installed? Update to the latest version:

<Callout type="tip" title="Easy path: plugin-update skill">
  Run <a href="/brewtools/skills/plugin-update/"><code>/brewtools:plugin-update</code></a> inside a Claude Code session. It checks versions,
  runs the full update chain, and prompts you to reload -- no manual commands needed.
</Callout>

Or run the update commands manually:

```bash
claude plugin marketplace update claude-brewcode
claude plugin update brewcode@claude-brewcode
claude plugin update brewdoc@claude-brewcode
claude plugin update brewtools@claude-brewcode
claude plugin update brewui@claude-brewcode
```

<Callout type="note" title="After updating: reload required">
  Run <code>/reload-plugins</code> inside your session (preferred), or type <code>exit</code> and run <code>claude</code> again (fallback). Updates are not active until a reload.
</Callout>

## Troubleshooting

<Callout type="warning" title="Common issues">
  **Plugins don't appear in `claude plugin list`**
  -- Make sure the marketplace is added: `claude plugin marketplace add https://github.com/kochetkov-ma/claude-brewcode`.
  Reinstall and restart Claude Code.

  **`/brewcode:*` commands are not recognized**
  -- Restart Claude Code after installation. Plugins only load at session start.

  **`timeout` command missing on macOS**
  -- Brewcode's session-start hook expects `timeout`/`gtimeout`. Install it with `brew install coreutils`.

  **`CLAUDECODE` environment variable interferes with launch**
  -- Run `unset CLAUDECODE` before running `claude` in scripts (applies to v0.2.47+).
</Callout>
