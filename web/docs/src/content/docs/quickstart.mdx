# Quick Start

The first ten minutes: conventions, domain agents, a task board and a project-tailored review skill. Run each setup generator in its own fresh session. New here? Follow the [recommended flow](/recommended-flow/).

<Callout type="note" title="Before you begin">
  Install Claude Code and the plugins first: see [Installation](/installation/). A skill ending in `-setup` installs a mechanism you use afterwards; the ordered list lives in [Full Setup](/full-setup/).
</Callout>

## Full workflow

<Steps>
  <li class="step step-primary">
    <div>
      <strong>Install the plugins</strong>
      <p>Add the marketplace and install brewcode once per machine. The task board needs brewtools, so install it too.</p>
      <pre><code>claude plugin marketplace add https://github.com/kochetkov-ma/claude-brewcode
claude plugin install brewcode@claude-brewcode
claude plugin install brewtools@claude-brewcode</code></pre>
    </div>
  </li>
  <li class="step step-primary">
    <div>
      <strong>Check the setup dashboard</strong>
      <p>The dashboard probes eleven setups and prints the command for each. It runs no setup itself.</p>
      <pre><code>/brewcode:setup-status</code></pre>
    </div>
  </li>
  <li class="step step-primary">
    <div>
      <strong>Write the project conventions</strong>
      <p>Parallel agents extract etalon classes and coding, testing and architecture patterns into `.claude/convention/`.</p>
      <pre><code>/brewcode:convention-setup install</code></pre>
    </div>
  </li>
  <li class="step step-primary">
    <div>
      <strong>Create a domain agent team</strong>
      <p>Generates 5-20 project agents with self-selection and performance tracking, built on the conventions.</p>
      <pre><code>{"/brewcode:teams-setup install core \"one agent per bounded context, plus a migrations specialist\""}</code></pre>
    </div>
  </li>
  <li class="step step-primary">
    <div>
      <strong>Set up the task board</strong>
      <p>Deploys a file-based Kanban and a project-tailored `/task-spec` skill. Select the optional spec layer when asked.</p>
      <pre><code>{"/brewtools:task-board-setup install . \"one lane per service\""}</code></pre>
    </div>
  </li>
  <li class="step step-primary">
    <div>
      <strong>Add your first task</strong>
      <p>Create the task, then resolve it by its unique title. <code>/task-spec</code> needs an existing task record and creates none.</p>
      <pre><code>{"/task-board add \"Implement JWT authorization with role-based access\"\n/task-spec \"Implement JWT authorization with role-based access\""}</code></pre>
    </div>
  </li>
  <li class="step step-primary">
    <div>
      <strong>Generate the deep review skill</strong>
      <p>Writes a project-tailored `/superreview` skill into `.claude/skills/`. The default depth runs your build, lint and test gates plus an intent check; a depth word such as `deep` adds domain experts and a validator.</p>
      <pre><code>{"/brewcode:superreview-setup install \"QUICK depth; gate on the existing build and lint commands\""}</code></pre>
    </div>
  </li>
</Steps>

<Spoiler id="step-details" title="Step details: reload, teams, tasks and timers">
  Run `/reload-plugins` inside a session after installing.

  Remove a team later by name: `uninstall core`, or `purge core` to drop its archive and trace files too.

  The board returns the task ID, which `/task-spec` accepts if titles overlap. If the spec layer was omitted, run task-board setup's `upgrade` and select it. `/task-spec` researches the codebase, asks clarifying questions and fans out to domain agents; methodology, spec and design land under `.claude/features/`.

  When a top-level task becomes active, the main session's task-board announces its hourly anti-drift cron, with a cadence you choose or an opt-out. Timers depend on the active session and runtime limits.

  Distributed plugin skills run only on your explicit command. Three exceptions: Claude can run `/brewdoc:publish`, `/brewtools:text-optimize` and `/brewtools:text-human` mid-task.
</Spoiler>

## What's next

<Callout type="warning" title="Update Claude Code first">
  The mods in the last row need Claude Code 2.1.301 or newer. Check with `claude --version`; if it is lower, run `claude update` and restart Claude Code (`exit`, then `claude`).
</Callout>

| Goal | Command |
|------|---------|
| [Deep review](/brewcode/skills/superreview-setup/): invoke the generated skill | `/superreview` |
| [Extract rules](/brewcode/skills/rules/) from conventions and commits | `/brewcode:rules "derive rules from .claude/convention/, one file per domain"` |
| [Optimize prompts](/brewtools/skills/text-optimize/) and agents | `/brewtools:text-optimize .claude/agents/` |
| [Brewcode mods](/mods/overview/): prompt placeholders, plan-mode effort | `claude plugin install brewmod-placeholders@claude-brewcode`<br />`claude plugin install brewmod-plan-effort@claude-brewcode` |

All 27 skills are listed on the plugin pages: [brewcode](/brewcode/overview/), [brewtools](/brewtools/overview/), [brewdoc](/brewdoc/overview/), [brewui](/brewui/overview/).
