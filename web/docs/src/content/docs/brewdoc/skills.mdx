# Skills

Skills (recipes) are slash commands that define *what* to do. Brewdoc includes 5 skills focused on doc-staleness tracking, memory-sync generation, Markdown → PDF conversion and content publishing -- each works independently with no prior setup required.

<Callout type="note" title="The -setup naming rule">
  A `-setup` suffix marks a skill that **installs a mechanism you afterwards use instead of the skill** (project-local hooks, a generated `/memory-sync`). Both setup skills implement `status | install | upgrade | enable | disable | uninstall | purge`. Every brewdoc skill except `/brewdoc:publish` is user-invoked only (`user-invocable: true` + `disable-model-invocation: true`); `publish` is model-invocable, see the [FAQ](/faq/#auto-invoke).
</Callout>

## Summary table

| # | Skill | Command | Model | Purpose | Arguments |
|---|-------|---------|-------|---------|-----------|
| 1 | docsync-setup | [/brewdoc:docsync-setup](/brewdoc/skills/docsync-setup/) | sonnet | Track and fix stale project docs via hooks | `[status\|install\|upgrade\|enable\|disable\|uninstall\|purge] [sync [--all]\|reread\|frontmatter] \| free-text` |
| 2 | my-claude | [/brewdoc:my-claude](/brewdoc/skills/my-claude/) | opus | Generate documentation about Claude Code installation | `[ext [context]] \| [r <query>]` — no args = internal installation docs |
| 3 | memory-sync-setup | [/brewdoc:memory-sync-setup](/brewdoc/skills/memory-sync-setup/) | opus | Generator: emits a project-tailored `/memory-sync` skill into the target repo — it never syncs memory itself | `[status\|install\|upgrade\|enable\|disable\|uninstall\|purge] [fine-tune-prompt]` |
| 4 | md-to-pdf | [/brewdoc:md-to-pdf](/brewdoc/skills/md-to-pdf/) | sonnet | Convert Markdown to PDF (reportlab / weasyprint) | `<file.md> [--engine name] ["prompt"] \| styles \| test` — no args = help |
| 5 | publish | [/brewdoc:publish](/brewdoc/skills/publish/) | haiku | Publish text, files, or multi-file sites to brewpage.app — returns a shareable URL | `<text\|file_path\|directory_path\|zip_path> [--ttl N] [--entry filename] [--delivery-mode path\|subdomain]` |

<Callout type="tip" title="Standalone">
  All five skills can be used independently -- they require no dependency on the other plugins in the suite. The [brewcode mods](/mods/overview/) add prompt placeholders and plan-mode effort.
</Callout>
