# Introduction

**Brewcode** is a plugin suite for Claude Code: project conventions and rules, domain agent teams, multi-agent quorum review, semantic code search, and tooling to build your own skills, agents, and hooks. Recipes (skills) define what to brew, brewers (agents) do the work, and hooks manage prompt-time injection.

Every skill here is invoked by you typing `/plugin:skill`. None of them auto-activate — see the [FAQ](/faq/#auto-invoke) for why that is deliberate.

<Callout type="tip" title="Start with the project foundation">
  Run setup-status first. Establish semantic search, run convention-setup before teams-setup,
  configure agent consumers, then install the task board and finish with documentation sync.
  Follow the [Full Setup](/full-setup/) run-list one setup per session.
</Callout>

**Naming rule:** a skill whose name ends in `-setup` installs a mechanism into the project — after it runs you use the installed thing, not the skill. Recurring tools keep bare names and are correct to run over and over. See [Full Setup](/full-setup/) for the ordered run list.

## What makes it different

<CardGrid>
  <Card title="Task board and methodology" icon="document" href="/brewtools/skills/task-board-setup/">
    Domain methodology, per-task work/review/test plans, and a task graph. Active top-level tasks
    get unique hourly session anti-drift timers unless you override them; specs are optional.
  </Card>
  <Card title="Quorum code review" icon="search" href="/brewcode/skills/superreview-setup/">
    3 to 5 parallel reviewers work independently. Results are merged via a
    quorum algorithm (2/3 agreement). Deduplication and ranking by severity.
  </Card>
  <Card title="Convention setup" icon="book" href="/brewcode/skills/convention-setup/">
    Extracts etalon classes, patterns, and architecture into convention docs,
    then syncs the distilled rules into <code>.claude/rules/</code>.
  </Card>
  <Card title="Skills and agents" icon="settings" href="/brewcode/skills/">
    27 skills and 8 specialized agents across 4 plugins. Built-in tools for
    creating your own skills, agents, and hooks. Prompt optimization included.
  </Card>
  <Card title="One setup dashboard" icon="clipboard" href="/full-setup/">
    <code>/brewcode:setup-status</code> reports which of the 11 setups are installed, stale,
    disabled, partial or missing here, and prints the exact command for each row.
  </Card>
</CardGrid>

## What's included

| Plugin | Purpose | Skills | Agents | Hooks |
|--------|---------|--------|--------|-------|
| **brewcode** | Conventions and rules, agent teams, semantic search, quorum review, skill/agent/hook creation | 9 | 5 | 4 |
| **brewtools** | Text utilities, secrets scanning, SSH, deploy, manager mode, the opt-in hook layer | 13 | 3 | 2 |
| **brewui** | UI / visual / creative tools (placeholder, empty) | 0 | 0 | — |
| **brewdoc** | Documentation tools: doc-staleness tracking, memory sync, setup docs, PDF, publishing | 5 | 0 | — |

All four plugins install with a single marketplace and load automatically with every Claude Code session.
The suite has six registered plugin hooks; additional setup-installed project hooks are separate.
