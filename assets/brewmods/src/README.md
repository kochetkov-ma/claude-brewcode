# brewmods GIF sources

One renderer, one story per GIF. `render.html?story=<name>` renders `#hero` (terminal-only frame: title bar with chapter and progress, the captured terminal, a caption bar) at any `&t=<s>` from `<name>.story.js` (storyboard: beats, keycaps, captions, `⏩` chips, `facts`, `bottle`, optional `window`, `marks` and `allow`; edit by hand) and `<name>.data.js` (screens; generated, never edit). `&bottle=1` renders `#bottle`, the ASCII fermenter alone, for the README image above the GIF. `&scene=1` renders `#scene`, a drawn scene (`story.scene`, no captures, no `data.js`). Every screen is a real tmux capture in `<name>.captures/`; a missing one renders as `TODO-CAPTURE:<beat>` and keeps `--check` red. `marks` = highlight boxes over captured rows, `{at, until, screen, rows: [r0, r1], cols?, tone: 'gold'|'teal', has, hold?}` (0-based; no `cols` = column 0 to the longest row), drawn under the keycap with a 0.25 s fade in and out inside `[at, until)`, at most two at once; teal (xterm 73) = plan mode. Output: `../<name>.gif`, `../<name>-still.png`, `../<name>-bottle.gif` (only with `story.bottle`), `<name>.manifest.json`.

Record needs ffmpeg, gifsicle, Google Chrome and network (Google Fonts); about 70 s per story.

Size: the frame is the terminal window, `ceil(cols x 8.4) + 30` CSS px wide (88 cols: 770), drawn at 2x and saved 1152 px wide (1.5x, sharp on HiDPI at the 700-800 px the docs and GitHub show it). Text reads at 13-15 px there. The docs cap `.prose p[align='center'] img { max-height: min(55vh, 480px) }` would shrink a 30-row frame to 540 px wide; `web/docs/src/styles/global.css` lifts it for `/brewmods/*.gif` except `/brewmods/hub*` (`hub.gif`, `hub-mini-*`). The terminal encode walks `LADDER` (256 colours down to 32 + lossy 30) and stops at the first rung <= 3.5 MB; a swatch keeps every capture fg colour plus the mark colours (`--gold`, `--plan` in `render.html`) in the palette, each one's nearest entry within RGB 4 is snapped onto it (exact hues), and the manifest records the rung (`colors`, `lossy`). The `hub-mini` scene is 640x248 CSS px at 2x, saved 800x310 with `flags=area` (no ringing outside the palette), 12 fps, 84 frames; each twin is a self-contained card (opaque bg + 1 px border in the `counter` role), so either reads on a white or a dark page. Its encode snaps every palettegen entry onto the nearest blend of two palette roles and runs `gifsicle -O1` (`-O2`/`-O3` merge the identical empty-counter tail frames). The bottle is 420 px wide (README shows it at 200-260 px), a 5 s loop at 6 fps; its grain re-rolls every 3rd frame and its waves stay slow, so the encode ladder stops near 0.45 MB (`BOTTLE_TARGET`), hard cap 1 MB.

`--check` gates: loop inside the story's `window` (default 30-38 s); keycaps only from the macOS allow-list (`⇥ tab`, `⏎ enter`, `⎋ esc`, arrows, `⌫ delete`, `⇧⇥ shift+tab`, `⌃O ctrl+o`); no `hover`, `2.1.296`, `Backspace`, `⌘`, Cyrillic; no `TODO-CAPTURE`; `story.bottle` well formed when set (unset: no bottle file, no manifest entry); every story fact true on its captured screen (`has` present, `lacks` absent); `marks`: each box's screen shown every frame of `[at, until)` with its typing finished, rows/cols inside `story.term`, edge rows not blank, `has` inside the box, no `++/` in its rows or in any caption, chapter or `aria`, held >= 1.2 s (or its `hold`), `until` <= `end`, tone `gold`|`teal`, overlaps only on one screen, at most two at once; every `"quote"` in `story.aria` on a captured screen; data equal to a fresh `--embed`; each typing screen's prompt row reads `❯` + the typed text; captures at `story.term`, ANSI text equal to the plain capture, no home/tmp paths, profile dirs (`.claude-<x>/`, `.codex/profiles/`), debug, hook or `Plugins updated|reload-plugins` rows (`story.allow` cuts only a token from `ALLOWABLE`, `reload-plugins` for `update-flow`, before this test: paths on the same row still fail), no old dialog wording (`(global) as drafted`, `do not ask where`), no error rows (`no matches found`, `command not found`, Traceback, `*Error`; WARN on `unknown placeholder`); GIF inside the window, 1152 px wide, at most 5 MB (WARN above 3.5 MB), recorded from the current sources (`<name>.manifest.json`); its encode rung in the manifest (WARN on the last rung or none recorded); still and bottle equal to the manifest; one sha256 for the repo and docs copies of the GIF (WARN while `../brewcode-app/site/main/public/mods/<name>.gif` differs, override `BREWCODE_APP_DIR`). Record adds seam SSIM >= 0.985, bottle <= 1 MB (target 0.45 MB) and 0 page errors.

Scene `--check` gates (instead of the capture gates and the bottle): `scene-story` (theme, the 9 roles `bg line counter tapBody handle beer beerHi foam foamHi` as `["#RRGGBB", cite]`, `border` names a role, loop 6-8 s, still inside it, size 640x248, the twin names this story back with the other theme and the same loop/fps/still/size); `scene-tokens` (each hex equals its cite: `tokens.css <theme> <token> [over <token>]` in `../brewcode-app/site/main/src/styles/tokens.css`, rgba composited over the second token, or `render.html <selector>`; WARN when brewcode-app is missing); `gif-dims` 800x310; `gif-frames` 84, 7.00 +-0.05 s; `gif-size` <= 300 KB (WARN > 250 KB); `gif-palette` (no local tables, every global entry but #000 padding, never drawn, within RGB 12 of a 2-role blend); `gif-no-loader` (frames after 0 start at y >= 10, frame 0 rows 0-9 only card bg + border, manifest `scene.topBand` true); then recorded, still (800x310), docs copy, brewcode-app WARN as above.

Rules: draw only captured rows and proven keys; if the real flow needs another key, add its keycap and its capture. Typing frames reuse the screen captured after the last typed key, its prompt row (styles kept) cut to the typed prefix; a token lands whole, as its own capture or via `from` when the capture's band already shows it, since the band changes only once it is complete. A keycap stays on the prompt row of the screen at its press; while caps overlap, the latest press shows. Captions change with the screen they describe. Set each `⏩` factor from the session transcript: real seconds in the span / shown seconds; keep the rows in `<name>.captures/timings.txt`.

Publish: stable direct URLs, never renamed: `https://doc-claude.brewcode.app/brewmods/<name>.gif` (Record copies it) and `https://brewcode.app/mods/<name>.gif` plus `<name>-still.png`, its reduced-motion poster (`ModDemo.astro`; copy both by hand to `../brewcode-app/site/main/public/mods/`); embed under a stable page anchor (heading slug or `id`) so the link can go to a person. The bottle is for the READMEs only: one per README, at the top (`placeholders`, `plan-effort`).

`hub.gif` (800x932, 10 s) predates this pipeline: no story, no `--check`; `hub-mini-*` is its small drawn stand-in. Its `../hub-still.png` is frame 126 (t=8.33 s, the `4/4 served` stage), native size, stored as a palette PNG (byte copy of brewcode.app's). Same pixels (AE 0), not the same bytes: `ffmpeg -i ../hub.gif -vf 'select=eq(n\,125),format=rgb24' -fps_mode passthrough -frames:v 1 f.png && pngquant 256 --nofs --speed 1 -o ../hub-still.png f.png`; re-cut it whenever `hub.gif` changes.

`banner-reminders.html` renders `../banner-reminders.png` (1280x640 share image, layout measured from `banner-plan-effort.png`; brewcode-app `site/main/public/og/mods-reminders-og.png` is a copy). Run from this dir: `"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --hide-scrollbars --force-device-scale-factor=1 --window-size=1280,640 --virtual-time-budget=10000 --screenshot=$PWD/../banner-reminders.png file://$PWD/banner-reminders.html` (network for Google Fonts).
