# brewmods GIF sources

One renderer, one story per GIF. `render.html?story=<name>` renders `#hero` (terminal-only frame: title bar with chapter and progress, the captured terminal, a caption bar) at any `&t=<s>` from `<name>.story.js` (storyboard: beats, keycaps, captions, `⏩` chips, `facts`, `bottle`, optional `window`; edit by hand) and `<name>.data.js` (screens; generated, never edit). `&bottle=1` renders `#bottle`, the ASCII fermenter alone, for the README image above the GIF. Every screen is a real tmux capture in `<name>.captures/`; a missing one renders as `TODO-CAPTURE:<beat>` and keeps `--check` red. Output: `../<name>.gif`, `../<name>-still.png`, `../<name>-bottle.gif`, `<name>.manifest.json`.

| Story | GIF | Terminal | Loop |
|---|---|---|---|
| `placeholders` | hero, usage first: `++` list, `↑` `⇥` insert `++r`, the band, send; one quick `/placeholders global add ++db`; plan mode: caret on `++db`, send; `++db ++m` with the teal plan part; `++/` | 88x30 | 35.8 s |
| `placeholders-full-text` | `++m` cut row -> `++m?` -> Enter fills `/placeholders show ++m` -> Enter prints | 88x30 | 24 s |
| `plan-effort` | Shift+Tab into plan mode, first prompt: toast + teal row, Shift+Tab out | 88x22 | 23 s |

| Step | Command (repo root unless noted) |
|---|---|
| Capture | cwd `~/brewery`, `unset CLAUDECODE`, `CLAUDE_CODE_DISABLE_CLAUDE_MDS=1 CLAUDE_CODE_DISABLE_AUTO_MEMORY=1`, mod copies whose global layer is a scratch dir: `tmux new -d -s ph -x 88 -y <story.term.rows> 'claude --setting-sources project,local --strict-mcp-config --permission-mode default --allowedTools Bash Read Grep Glob Edit Write --settings {"tui":"default","promptSuggestionEnabled":false,"spinnerTipsEnabled":false} --plugin-dir <mod>...'` (`-y` 30; plan-effort `-y 22` plus `--model sonnet --effort high`; main-screen TUI; no ghost suggestion or spinner tip rows; `Edit Write` because the hero turn fixes `brew.js`, so no approval dialog mid-turn; no `--debug`; `--safe-mode` disables plugins; tmux `focus-events on`). Per key `tmux send-keys -t ph <key>`, then `bash assets/brewmods/src/capture.sh ph <screen> assets/brewmods/src/<name>.captures` (names: `screens` in the story). `PH_SCROLL_UP=<n>` = the view `n` rows up the scrollback (a scrolled terminal, caret hidden); `PH_TMUX_SOCKET` = `tmux -L` name |
| Embed | `node assets/brewmods/src/record-gifs.mjs <name> --embed` |
| Preview | From the record dir: `node <repo>/assets/brewmods/src/record-gifs.mjs <name> --preview 7.5` (PNG in the tmp dir; `--width <px>` for another size) |
| Record | `cd "$(mktemp -d)" && npm i playwright-core@1.64.0 --no-package-lock && node <repo>/assets/brewmods/src/record-gifs.mjs <name>`: writes `../<name>.gif`, `../<name>-still.png` (frame at `still`), `../<name>-bottle.gif`, copies the GIF (not the still: unreferenced there, gitignored by `*.png`) to `web/docs/public/brewmods/`, writes `<name>.manifest.json`. `--out <dir>` = test run that touches nothing |
| Check | `node assets/brewmods/src/record-gifs.mjs <name> --check` (node only); rc 0 = no FAIL |

Record needs ffmpeg, gifsicle, Google Chrome and network (Google Fonts); about 70 s per story.

Size: the frame is the terminal window, `ceil(cols x 8.4) + 30` CSS px wide (88 cols: 770), drawn at 2x and saved 1152 px wide (1.5x, sharp on HiDPI at the 700-800 px the docs and GitHub show it). Text reads at 13-15 px there. The docs cap `.prose p[align='center'] img { max-height: min(55vh, 480px) }` would shrink a 30-row frame to 540 px wide; `web/docs/src/styles/global.css` lifts it for `/brewmods/*.gif` (not `hub.gif`). The bottle is 420 px wide (README shows it at 200-260 px), a 5 s loop at 6 fps; its grain re-rolls every 3rd frame and its waves stay slow, so the encode ladder stops near 0.45 MB (`BOTTLE_TARGET`), hard cap 1 MB.

`--check` gates: loop inside the story's `window` (default 30-38 s); keycaps only from the macOS allow-list (`⇥ tab`, `⏎ enter`, `⎋ esc`, arrows, `⌫ delete`, `⇧⇥ shift+tab`, `⌃O ctrl+o`); no `hover`, `2.1.296`, `Backspace`, `⌘`, Cyrillic; no `TODO-CAPTURE`; `story.bottle` set; every story fact true on its captured screen (`has` present, `lacks` absent); every `"quote"` in `story.aria` on a captured screen; data equal to a fresh `--embed`; each typing screen's prompt row reads `❯` + the typed text; captures at `story.term`, ANSI text equal to the plain capture, no home/tmp paths, debug or `Plugins updated` rows, no old dialog wording (`(global) as drafted`, `do not ask where`), no error rows (`no matches found`, `command not found`, Traceback, `*Error`; WARN on `unknown placeholder`); GIF inside the window, 1152 px wide, at most 5 MB (WARN above 3.5 MB), recorded from the current sources (`<name>.manifest.json`); still and bottle equal to the manifest; one sha256 for the repo and docs copies of the GIF (WARN while `../brewcode-app/site/main/public/mods/<name>.gif` differs, override `BREWCODE_APP_DIR`). Record adds seam SSIM >= 0.985, bottle <= 1 MB (target 0.45 MB) and 0 page errors.

Rules: draw only captured rows and proven keys; if the real flow needs another key, add its keycap and its capture. Typing frames reuse the screen captured after the last typed key, its prompt row (styles kept) cut to the typed prefix; a token lands whole, as its own capture or via `from` when the capture's band already shows it, since the band changes only once it is complete. A keycap stays on the prompt row of the screen at its press. Captions change with the screen they describe. Set each `⏩` factor from the session transcript: real seconds in the span / shown seconds; keep the rows in `<name>.captures/timings.txt`.

Publish: stable direct URLs, never renamed: `https://doc-claude.brewcode.app/brewmods/<name>.gif` (Record copies it) and `https://brewcode.app/mods/<name>.gif` plus `<name>-still.png`, its reduced-motion poster (`ModDemo.astro`; copy both by hand to `../brewcode-app/site/main/public/mods/`); embed under a stable page anchor (heading slug or `id`) so the link can go to a person. The bottle is for the READMEs only.

`hub.gif` (800x932, 10 s) predates this pipeline: no story, no `--check`. Its `../hub-still.png` is frame 126 (t=8.33 s, the `4/4 served` stage), native size, stored as a palette PNG (byte copy of brewcode.app's). Same pixels (AE 0), not the same bytes: `ffmpeg -i ../hub.gif -vf 'select=eq(n\,125),format=rgb24' -fps_mode passthrough -frames:v 1 f.png && pngquant 256 --nofs --speed 1 -o ../hub-still.png f.png`; re-cut it whenever `hub.gif` changes.
